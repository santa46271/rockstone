# Часть 2: TopTracker

## Архитектура
Модуль хранит N последних действий с очисткой по времени:
- Двусторонняя очередь (`std::deque`)  
  Оптимальна для удаления с начала и добавления в конец (O(1))
- Мьютекс (`std::mutex`)  
  Гарантирует потокобезопасность
- Хронометраж (`std::chrono`)  
  Точное измерение времени

## Алгоритм
1. При добавлении/чтении:
   - Удаляются действия старше `timeout`
   - Удаляются лишние действия (если превышен `max_actions`)
2. Данные возвращаются в обратном порядке (новые → старые)

## Производительность
- Добавление: O(1) (амортизированно)
- Очистка: O(k) (k = число удаляемых элементов)
- Чтение: O(n)
